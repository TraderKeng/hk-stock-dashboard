## 1. 產業運作方式

**產業範圍。** 「軟件（基建）」在港股本組成份中，指向**基礎大模型與 AI 雲／API 基礎設施**提供商：向開發者與企業出售模型推理 API、私有化部署、語音／多模態能力與相關工具鏈。與「應用層」視覺／車載軟件（見軟件應用組）相比，更靠近算力、模型訓練與平台層。

**主要商業模式。**
1. **API／Token 計量收費**：按调用量或 token 計費，毛利依賴模型效率與雲成本。
2. **私有化／行業解決方案**：政企採購、專有雲部署，合同週期長、確認收入節奏不均。
3. **多模態產品矩陣**：語音、視頻、音樂、文本等（MiniMax 披露方向，來源 1）；通用對話與代碼／エージェント能力（智譜 GLM 系列，來源 2）。

**關鍵成功因素。** (i) 模型能力與評測排名；(ii) 推理成本與毛利率；(iii) 政企信創／招標准入；(iv) 算力供應與資本開支；(v) 人才與安全合規。

**當前週期。** 收入高增與虧損並存：MiniMax 2026H1 收入約 +283%，智譜約 +400% 量級（來源 1、2），但經調整仍大額虧損。二級市場自高位大幅回撤（組 20d −27.5%），本日為弱勢中的技術反彈。

---



**單位經濟與資本週期。** 基礎模型公司的核心矛盾是：收入按 API／項目快速擴張的同時，訓練與推理算力、人才薪酬與安全合規形成剛性成本。短期可用融資與股權激勵支撐份額，但若 Token 單價持續下行而利用率不足，毛利率改善會慢於收入。港股兩成份上市後波動顯著，反映市場對「高增＋長虧」路徑的風險偏好變化。

**競爭層級。** 第一層是互聯網巨頭自研模型＋雲綁定；第二層是獨立模型公司（本組成份）以 API 與私有化求存；第三層是開源模型降低客戶轉換成本。本組成份必須在垂直場景深度、推理成本或政企准入上建立差異，否則易陷入價格戰。20d 組跌幅逾兩成後的反彈，更多是風險偏好修復，而非基本面已確認拐點。

**披露與投資者溝通。** 兩成份均為較新上市的加權投票權／新經濟結構，業績公告中 IFRS 與非 IFRS（經調整）並列；市場定價往往更看收入增速、毛利率軌跡與現金消耗，而非單期 IFRS 盈虧。在 20d 大幅回撤後解讀「轉強」，應同時檢查成交能否放大、以及是否僅隨大盤科技股共振反彈，避免把技術標籤等同基本面拐點。

## 3. 重要行業趨勢

1. **增收不增利仍是主旋律**：高增收入伴隨高研發與算力開支（來源 1、2）。
2. **價格競爭**：API 降價換份額，壓縮單位經濟模型。
3. **評測與口碑驅動訂單**：開源／閉源路線並行，企業採購看重合規與私有化。
4. **二級市場波動極大**：本組 20d −27.5%、10d 廣度 0%，顯示風險偏好急劇收斂後的反彈脆弱。

## 4. 未來 12 個月催化劑與風險

**催化劑**
- 後續季度收入增速與毛利率／虧損收窄披露（預計節奏不一，**此為估計**）。
- 政企大模型採購與信創招標落地。
- 多模態產品商業化（視頻／語音）ARPU 提升。

**風險**
- 持續大額虧損與再融資／稀釋。
- 價格戰與雲成本上升。
- 技術面：若反彈失敗，20d 深跌格局易延續——**不宜僅因轉強標籤外推趨勢**。
- 監管與內容合規成本。
